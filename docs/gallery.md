# Галерея компонентов

`ComponentGallery` — единая интерактивная доска визуальной приёмки `share-ui`.
Она рендерит настоящие публичные компоненты, а не их скриншоты или отдельные
копии. Поэтому изменение токенов, responsive CSS или поведения сразу видно в
автономной витрине и во встроенной странице consumer-приложения.

## Автономный запуск

```bash
npm run dev
```

Vite открывает `demo/App.vue`, который содержит только общий canvas и
`ComponentGallery`. Акцент и остальные semantic tokens можно менять через
DevTools либо во временном style override.

## Встраивание в приложение

Галерея поставляется отдельным entry point:

```vue
<script setup>
import { ComponentGallery } from '@sylvieshare/share-ui/gallery'
</script>

<template>
  <ComponentGallery />
</template>
```

Для служебной страницы рекомендуется lazy import: галерея нужна разработчикам
и администраторам, поэтому её render-код не следует загружать на обычных
пользовательских маршрутах.

## Правило полноты

`src/lib/componentGalleryCatalog.js` перечисляет все канонические публичные
Vue-компоненты и compatibility aliases. Каждый канонический компонент должен
иметь реальный интерактивный пример с `data-share-gallery` в
`ComponentGallery.vue`.

Тест `tests/componentGallery.test.js` проверяет три инварианта:

1. каждый Vue-компонент из основного public API зарегистрирован в каталоге;
2. каждый alias указывает на каноническое имя;
3. каждый канонический компонент присутствует на доске.

Таким образом, pull request с новым публичным компонентом не пройдёт тесты,
пока автор не добавит визуальный пример. Для одного компонента желательно
показывать основные варианты и состояния: default, active/disabled/error,
responsive или открытый overlay — в зависимости от его контракта.

## Почему это не отдельный Storybook

На текущем размере библиотеки отдельный Storybook создал бы второй набор
stories и отдельную интеграцию тем. Встраиваемый Vue-компонент решает обе
актуальные задачи одним источником правды: локальная разработка и просмотр в
реальном consumer theme. Если позже понадобятся visual regression, controls и
документирование props, Storybook можно подключить как оболочку над теми же
примерами, не заменяя галерею.
